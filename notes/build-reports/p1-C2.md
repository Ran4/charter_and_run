## CONTRACT CHANGES
1. **Landmark `plaza` moved** (own block, via `f.mark` in `plaza()`): `(0, 0, 0)` → **`(0, 6.8, π)`**
   on block (2,3). Why: the fountain's central column (collider r 0.45, top 99) stands at (0, 0), so
   the old spot was inside a solid. The new spot is just outside the rim's south side, facing the
   fountain (and the north arcade and Christmas tree in the `views` shot). `goto plaza radius 4
   onFoot` still means "by the fountain". `fena_plaza` stays at (0, 0) (it circles r 1.2 in the water,
   clear of the r 0.45 column).
   Patch for `src/world/landmarks-island.js`: `plaza: { b: [2, 3], at: [0, 6.8], yaw: PI },` and the
   DESIGN §6.3 plaza row `plaza (0, 6.8, π)`.
2. **Engine note (no patch needed, DESIGN §14.7 wording)**: collision kind `'prop'` is reserved.
   `car.collideStatic` treats any block with `kind === 'prop'` as a smashable prop and reads
   `b.ref.def`. A static solid of kind `'prop'` from a block builder therefore throws every frame once a
   car touches it. I hit this in `fullstory` and fixed it in my file. Suggest one line in DESIGN §14.7:
   "block builders must not use collision kind `prop` (reserved for props.js)". Kinds used by C2:
   `building wall pole tree planter table crate stall bounce solid rim curb water` and `ramp`.
3. **Proposed `.gitignore` fix (Phase 2)**: `node_modules/` → `node_modules` so the symlinked
   `node_modules` in worktrees is ignored and the ownership check prints nothing.
4. No other landmark, API or signature changes. `centre.js` no longer imports `stub.js`.
